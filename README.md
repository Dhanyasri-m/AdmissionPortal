# 🎓 Web-Based College Admission Form with CFG Validation and Subnet Allocation

A modern web-based college admission system designed to simplify the admission process through intelligent data validation and automated network resource allocation.

This project combines **React.js**, **Context-Free Grammar (CFG) Validation**, and **Subnet Allocation** concepts to create a secure, scalable, and user-friendly admission management platform.

---

## 🚀 Project Overview

Traditional admission systems often rely on manual verification and basic input validation, leading to incorrect submissions, duplicate records, and inefficient processing.

This project introduces an intelligent admission platform that validates user input using **Context-Free Grammar (CFG)** and automates **IP subnet allocation** for departments, improving both data quality and network resource management.

## 🌐 CFG Validation

Unlike traditional form validation, this project introduces **Context-Free Grammar (CFG)** concepts to validate structured inputs such as:

- Student Name
- Email Address
- Phone Number
- Identification Details

This ensures syntactically correct and meaningful user input.

---

## 🌐 Automated Subnet Allocation

The project automatically allocates network subnets to academic departments based on student strength.

Benefits include:

- Efficient IP utilization
- Reduced manual work
- Conflict-free subnet allocation
- Better network scalability
